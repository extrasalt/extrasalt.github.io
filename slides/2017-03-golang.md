### How do you deploy a go app on the cloud?
- Compile your binary
- Create a dockerfile
- Add a base OS
- Add your binary
- Chmod it
- Set it as entrypoint
- Make an image with the dockerfile
- Upload the image to a registry
- Pull the image on your nodes and run
